# Portfolio Tracker - Releases

Этот репозиторий создан для публикации официальных сборок приложения **Portfolio Tracker** для Windows.

Исходный код проекта находится в приватном репозитории.

## Как скачать
1. Перейдите в раздел [Releases](../../releases).
2. Скачайте последний файл `PortfolioTracker_Setup_<версия>.exe`.
3. Запустите установщик.

## Документация
Инструкция по установке, удалению и резервному копированию прикреплена к каждому релизу.
